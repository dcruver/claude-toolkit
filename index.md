# claude-toolkit

The OKF bundle root for this repository. Every concept lives beside the source
it describes — `Greeter.py` is documented by `Greeter.md` in the same directory
— and each directory's own `index.md` lists what that directory holds.

- `okf list --missing` — in-scope sources with no concept yet
- `okf check` — concepts whose source has changed underneath them
- `okf index` — regenerate the per-directory `index.md` files
