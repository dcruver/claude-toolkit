description: Propose concrete hand-edits to tighten AI-generated code, without a full rewrite
---

Look at $ARGUMENTS (or the most recent AI-generated change if no argument given) and propose the specific hand-edits you'd make to tighten it — not a regeneration. For each edit: the exact line(s), what you'd change it to, and a short reason (too generic / dead code / wrong name / unnecessary abstraction / doesn't match surrounding style / etc).

Prefer several small, surgical edits over one large rewrite — the point is edits a human could type by hand in seconds, not a re-prompt.
